# Django Mastery

A collection of Django concepts from beginner to advanced, with practical code examples.

## 📚 Overview

This repository contains practical examples and explanations of Django concepts to help developers learn Django step by step, understand how it works, and improve their web development skills.

## 🎯 Topics Covered

- Django installation and project setup
- Projects and applications
- URL routing and views
- Templates and template inheritance
- Static files and media files
- Models, ORM, and database operations
- Migrations and Django Admin
- Forms and ModelForms
- CRUD operations
- User authentication and authorization
- Class-Based Views (CBVs)
- Middleware and signals
- File uploads and validation
- Django REST Framework (DRF)
- API development and authentication
- Error handling and best practices

*Topics will be added as the repository grows.*

## 🛠️ Technologies Used

- Python

- HTML and CSS

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/AJ126/django-mastery.git
cd django-mastery
```

**2. Create a virtual environment**

```bash
python -m venv venv
```

**3. Activate the virtual environment**

Windows:

```bash
venv\Scripts\activate
```

macOS/Linux:

```bash
source venv/bin/activate
```

**4. Install dependencies**

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install Django:

```bash
pip install django
```

**5. Run database migrations**

```bash
python manage.py migrate
```

**6. Start the development server**

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

*Note: Run Django management commands from the directory containing `manage.py`. The repository may contain multiple independent example projects, each with its own setup requirements.*
